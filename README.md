📊 Dashboard Project

Um dashboard moderno, responsivo e de alta performance construído com o ecossistema React.

🔗 **Acesse o projeto online:** (https://dashboard-matheus.vercel.app/)

## 🛠️ Tecnologias

* **Next.js** (App Router)
* **TypeScript**
* **Tailwind CSS**
* **Shadcn/ui**
* **Vercel** (Deploy & Hospedagem)

* 📈 Gráficos interativos e visualização de dados.
* 🌓 Suporte a Modo Escuro / Modo Claro.
* 📱 Design 100% responsivo (Mobile e Desktop).
